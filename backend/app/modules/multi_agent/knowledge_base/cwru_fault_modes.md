# CWRU 轴承故障知识库

> 本知识库面向 SKF 6205 轴承（CWRU 驱动端数据，采样率 12kHz）。
> 每个故障类型以 `##` 标题分隔，供 knowledge_tools 按关键词解析检索。
> 特征频率系数基于 SKF 6205 几何参数（转频 fr = 转速/60）。

---

## normal
- 特征频率公式: 无周期性冲击特征频率
- 典型频谱特征: 包络谱整体平坦，各特征频率处幅值极低（< 0.05），无显著谐波族
- 维护建议: 维持常规状态监测与定期润滑，无需停机检修
- 严重度分级: normal（健康）

## inner_race
- 特征频率公式: BPFI = 5.4152 × fr
- 典型频谱特征: 包络谱在 BPFI 及其谐波处出现峰值，伴随 ±fr 转频边带调制（内圈故障点随轴旋转，冲击幅值受负载区调制）
- 维护建议: 检查内圈滚道剥落/点蚀，重点关注 BPFI 谐波与转频边带，确认缺陷尺寸
- 严重度分级: 按 BPFI 幅值与边带能量分级（mild / severe）

## outer_race
- 特征频率公式: BPFO = 3.5848 × fr
- 典型频谱特征: 包络谱在 BPFO 及谐波处出现单一强峰，边带弱（外圈故障点位置固定，冲击稳定）
- 维护建议: 检查外圈滚道剥落/点蚀，重点关注 BPFO 特征频率及谐波间隔
- 严重度分级: 按 BPFO 幅值与谐波数量分级（mild / severe）

## ball
- 特征频率公式: BSF = 2.3567 × fr；2×BSF = 4.7134 × fr
- 典型频谱特征: 包络谱在 BSF / 2×BSF 处出现峰值，能量较分散，受保持架频率 FTF 调制，通常不如内外圈清晰
- 维护建议: 检查滚动体磨损/剥落，关注 BSF 谐波族与 FTF 边带，必要时更换整套轴承
- 严重度分级: 按 BSF 谐波族幅值分级（mild / severe）

## 附：SKF 6205 特征频率换算参考
- 转频 fr = 转速(rpm) / 60
- BPFO ≈ 3.5848 × fr
- BPFI ≈ 5.4152 × fr
- BSF ≈ 2.3567 × fr
- FTF ≈ 0.3983 × fr
