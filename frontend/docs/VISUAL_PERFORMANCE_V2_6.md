# V2.6 视觉、性能与文案维护说明

基线 `9661b992011bb7474f0e4aba461a5cc597b19202`。V2.4 Pico Agent 协议、业务 API、权限、研究目录 ID、Logo 和品牌红保持原契约。没有新增运行依赖，也没有重写后端业务、设备控制或部署系统。

## 动画与工厂

退出白纸展开为650ms，红块240ms后进入。`sampleC` 将平移限制到左边界，超过1的有界过冲转为左原点 scaleX，最终精确归位。认证清理、密码遮蔽、RouteReady、epoch、Resize与减少动画仍由原Provider管理。

工厂 `safePath` 和目标座位算法不变。`Route` 保存原折线累计弧长，整条路径使用同一单调五次时间曲线，只在起终点缓动，中间路点不重新停速。初始速度取首段切向投影并限幅；严格保留折线时，反向和转角无法同时保持二维速度方向连续，优先保证真实起点、原几何与安全。

渲染与预约共用 `sampleRoute`。时间检查保留10ms网格，并按双方路线的转角、预约起止时间拆分，完整机身 swept overlap 和原间距包络仍保留。不能以增加 bow 或跳过碰撞检查替代速度曲线。

## Pico

消息先进入真实列表并占位，业务请求立即发送。输入框自动缩高稳定后测量目标；飞行副本始终使用目标的最终宽高和换行，只用 translate3d 移动。目标整块视觉隐藏，滚动时从当前姿态续接到新锚点，截止时间不延长。宽度改变、离开消息视口、Resize、减少动画、关闭和卸载会恢复真实消息。

`PicoAvatar` 的 renderer、网格、材质和控制器在同一组件生命周期持续复用，ResizeObserver只更新绘图区。现有工作台路由已经隐藏Dock，不重复添加第二套角色状态。形变使用解析逆转置法线；纹理仅在可见输入变化时重画。deadline调度器在待机绘制间隔休眠，交互/语音/自主动作期间保持更高频率。低频绘制以小步推进真实时间；后台恢复清除旧计时，不补完隐藏期间动作。最后订阅者释放RAF、timer与监听。

开发环境表情控件是受控radio组，只有一个共享指示器。方向键/Home/End只滚动内部轨道，保留文档垂直位置。英文内部emotion ID不变，界面与无障碍标签统一中文。生产包继续不展示实验台。

## 研究舞台

Overview使用真实研究目录和数据资产登记，不再重复CWRU。矮桌面压缩重复来源说明，小屏内部滚动保留全部目录；各章节及详情仍保留来源。CWRU四类图例跨波形/FFT/特征空间共用名称，series ID分别使用wave/fft/feature前缀。FP-CNN使用发布的噪声与少样本成对结果；不平滑或补造数值。寿命共享几何保留同轴承、长度与每个actual逐点一致的守卫，null仍断线。

`sceneSources` / `figureSources`声明图形依赖：蒸汽需要steam与steam-analysis；寿命图需要xjtu-rul与rul-sde-pf。文章只加载当前与邻近图形；详情补取其必要来源，汇总详情才读取全目录。会话缓存去重，scope隔离公开与登录状态，refresh revision拒绝旧响应。Provider内的详情通过ensure主动请求，不单独复制状态。

`useStageTimeline` 从实际URL初始化。连续进度由 `paintStage` 写CSS变量、进度条和寿命局部裁切/游标；React只在挂载层、active和可访问性边界变化时提交。提交后用最新进度重画，保证反向、Resize和迟到数据姿态一致。单图option仅依赖自身来源，避免无关数据返回触发setOption。

ECharts通过 `chartLibrary` 注册当前实际使用的line/bar/scatter/heatmap/pie及必要组件，Canvas与SVG渲染器均保留。不得为缩包破坏详情或工厂图表。底部无效证据回跳块已移除，场景内完整实验入口保留。

迟到数据可能将普通寿命场景替换为共享曲线节点，原详情触发按钮随之卸载。抽屉关闭完成后显式恢复到当前可见场景的来源按钮，缺失时回到舞台标题，保持滚动位置；不依赖组件库保存的旧 DOM 引用。

## 后端与研究事实

AnomalyDetectService在首次使用时导入CNN/PINN模块，轻量SEQ_LEN常量不导入torch。单例初始化有锁，模型实现、权重路径、标签、推理与缺模型返回协议不变。视觉模型列表不再隐式预热；实际检测仍按需加载并缓存，失败可重试。未删除PyTorch、MQTT或视觉能力。

文案修订不改实验数值、单位、来源、权限和负R²。去除目录数量推断泛化、单点推断趋势、频带接近证明物理学习及“首次”等无相应证据的表述；保留混淆矩阵、物理先验、RUL/TTF和仿真边界。

另明确 t-SNE 嵌入不能单独证明分类性能、采纳率不能单独证明建议有效，构造设备目标域不能写成现场迁移验证；NEU-DET 钢材检测不能直接证明部件适用性，单次模型对照也不构成固定部署选型规则。重要文案共44项前后对照保存在仓库外。

## 验证与交付边界

前端执行 `npm test`、`npm run typecheck`、`npm run build`；后端执行隔离pytest。真实浏览器覆盖三种尺寸、双主题、减少动画、登录退出、Pico Agent和研究/工厂回归。审计、截图、录屏、性能原始数据、文案前后对照及验收状态在仓库外 `_agent_runs/gongye-internet-diagnosis/v2_6`。

性能按相同页面、窗口、Chromium和流程分开发/生产测量，不将RAF频率当角色绘制频率，不将一次短测当长期无泄漏。现场CNN/PINN权重、在线大模型、物理语音/触控板和GPU显存等没有实际证据时标UNVERIFIED。随机checkpoint只验证真实Torch推理代码路径，不代表训练效果或现场模型验收。
